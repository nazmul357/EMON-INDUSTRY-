## ✨ Features

- 📱 **Mobile-First Responsive Design:** Optimized for seamless viewing across smartphones, tablets, and desktop displays.
- ⚡ **Lightweight & Fast:** Built with pure HTML5, CSS3, and JavaScript for minimal load times.
- 🎨 **Dark Mode Theme:** Sleek modern UI inspired by glassmorphism and modern dashboard design.
- 🚀 **Automated CI/CD:** Powered by GitHub Pages for zero-downtime automated deployment on every commit.
